# AI 生成文に出やすい語彙と構文の一覧

AI が生成した日本語に出やすい語彙と構文を、書き換えの方針と並べてまとめる。
SKILL.md の「翻訳調と英語統語の排除」「演出の抑制」「LLM っぽい表現の禁止」の補足であり、そこで挙げた語の用例と直し方を引くために使う。
ここに載っている語は点検の対象であって、一律の禁止ではない。その分野で正当な用語や、比喩でない字義どおりの使い方は残す。

この一覧は、[yomiyasu](https://github.com/nanaism/yomiyasu) の `references/slop-catalog.md` を、この規範の表記と規則に合わせて書き直したものである。

## 比喩動詞

抽象的な出来事や技術的な操作を、比喩の動詞で言い換えている。

| 動詞 | 用例 | 直し方 |
|---|---|---|
| 効く、効いてくる | 「地味に効きます」「〜が効いてくる」 | 「〜の役に立つ」「効果がある」「〜を防げる」 |
| 壊れる | 「静かに壊れる」「もう片方が壊れる」 | 「要件を満たせなくなる」「例外が出る」「整合性が崩れる」 |
| 倒す | 「〜側に倒す」「残さない側に倒す」 | 「〜を原則とする」「除外する」「〜を採用する」 |
| 溶かす | 「時間を溶かしました」 | 「多くの時間を費やした」「調査に時間がかかった」 |
| 潰す | 「1つずつ潰していく」 | 「エラーを1件ずつ解消する」「原因を1つずつ検証する」 |
| 踏み込む | 「〜まで踏み込んで」 | 「〜の内部実装まで調べて」 |
| 引き返す | 「動かしながら引き返す」 | 「元の状態に戻す」「ロールバックする」 |
| 添える | 「経路が代わりに添える」 | 「参照する」「付与する」「渡す」 |
| 収斂する | 「その価格帯に収斂した」 | 「〜に決まった」「〜に落ち着いた」 |
| 沈黙する | 「静かに沈黙する」 | 「エラーを出さずに終了する」「応答しない」 |
| 黙って | 「黙って無視される」「黙って捨てられる」 | 「通知なく破棄される」「ログを出さずにスキップする」 |

## 英語の言い回しの直訳

| 英語の原表現 | 直訳の日本語 | 直し方 |
|---|---|---|
| silently fail、ignored | 「静かに壊れる」「黙って無視される」 | 「エラーを出さずに失敗する」「警告なしで無視される」 |
| the moment ... | 「〜した瞬間」「〜した瞬間に」 | 「〜するとすぐに」「〜した直後に」「〜した時点で」 |
| single source of truth | 「〜を正本にする」「〜の正本として」 | 「信頼できる唯一の情報源とする」「マスターデータとする」 |
| point to、suggest | 「〜を指している」「〜を示唆している」 | 「〜を表している」「〜を意味する」 |
| load-bearing | 「耐力のある」「構造を支える」 | 「外せない」、または何を支えているのかを書く |
| it is not X, it is Y | 「Xではなく、Yです」 | 「Yです」と書き、要らないXの否定を削る |
| delve into | 「〜に深く分け入る」「深掘りする」 | 「詳しく調べる」 |
| em dash | 「〜――とりわけ〜――は」 | 「〜をはじめとする〜は」のように助詞でつなぐ |

## 比喩名詞

障害、確認、役割、評価を、比喩の名詞や定型の言い方で表している。
字義どおりに使っているなら残す。

| 分類 | 語 | 用例 | 直し方 |
|---|---|---|---|
| 障害や失敗の比喩 | 「事故」「混ざる」「落とし穴」「破綻」「実害」「素通り」 | 「〜という事故」「落とし穴があります」 | 「不整合」「例外の発生」「考慮すべき点」 |
| 確認や検証の比喩 | 「実測」「疑う」「照合」「突き合わせる」「断定」「取り違える」 | 「実測では」「〜を取り違えると」 | 「計測値」「確認する」「比較して検証する」 |
| 役割や位置の比喩 | 「入口」「土台」「道具」「核心」「主役」「構図」「線引き」 | 「〜の入口として」「〜するための土台」 | 「導入」「前提条件」「基礎知識」 |
| 評価や結論の定型 | 「既定」「別物」「定番」「要点」「定石」「桁違い」 | 「既定では」「〜とは別物です」 | 「初期設定では」「性質が異なります」 |

## 体験を壮大にする熟語

個人のささやかな体験や日常的な判断を、重い熟語で教訓に仕立てている。
対象の語は「真理」「真実」「結末」「宿命」「運命」「境地」「極致」「究極」「虚飾」「虚像」「美学」「深淵」「禁欲的」「優美」「冷徹」「残酷」「凝縮」「結晶」である。
書き換えの例は `references/syntax-conversion.md` の「エッセイの例」にある。

## 質感や認知を装う語

具体的に見えて、何を操作し、何を調べたのかを書いていない。

| 分類 | 語 | 直し方 |
|---|---|---|
| 質感を装う語 | 「手触り」「肌感」「肌感覚」「体温」「温度感」「熱量」「血の通った」「泥臭い」 | 実際に操作した手順、ログ、計測値を書く |
| 認知を装う語 | 「解像度（を上げる、が高い）」「腹落ち」「メンタルモデル」「文脈」 | 何をどこまで調べ、検討したのかを書く。「文脈」を定式化の前の導入語として使うのはよい |
| 評価を装う語 | 「本質」「本質的」「地に足のついた」「等身大」 | 空疎な修飾を削り、事実を書く |
| 未定義の造語 | 「意思決定 OS」のような比喩による命名 | 標準的な用語か、機能の説明で書く |

## 前置きと定型の結び

読者の感情や理解を先回りして操作しようとする前置きと、後置きの句である。

| 分類 | 表現 | 直し方 |
|---|---|---|
| 前置き | 「重要なのは」「結論から言うと」「正直に言うと」「避けたいのは」「ここで注目すべきは」 | 前置きを丸ごと削り、要点の文から書き始める |
| 後置きのラベル | 「〜というわけです」「〜に他なりません」「〜と言えるでしょう」「面白いのはここです」 | 断定か、事実の記述で文を閉じる |
| 定型の結び | 「いかがでしたでしょうか」「ぜひ試してみてください」「〜の参考になれば幸いです」 | 形式的な呼びかけを削り、本文の自然な結びで終える |
